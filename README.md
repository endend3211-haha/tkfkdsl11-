# R08 ↔ MemoMind One 브릿지 안드로이드 앱 프로젝트

R08 스마트링의 블루투스 HID 입력 신호를 가로채어 **MemoMind One 스마트 글라스**의 메뉴 이동(Up/Down), 항목 선택(Click), 뒤로가기(Back) 동작으로 변환해주는 안드로이드 브릿지 앱입니다.

---

## 주요 기능
1. **실시간 신호 모니터**: R08 링에서 들어오는 실제 키코드(`KEYCODE_VOLUME_UP`, `KEYCODE_MEDIA_NEXT` 등)를 앱 화면에서 즉시 확인
2. **원클릭 제스처 학습(매핑) 모드**: R08 링 펌웨어마다 다른 키코드를 버튼 클릭 후 링을 만져서 즉시 매핑 가능
3. **3가지 제어 모드 지원**:
   - **하이브리드 모드**: UI 포커스 이동 시도 후 불가능한 화면에서는 자동 스와이프
   - **스와이프 전용 모드**: 대시보드 위젯이나 텔레프롬프터 스크롤에 최적화
   - **포커스 전용 모드**: 앱 내 세부 메뉴 탐색 및 버튼 클릭에 최적화
4. **더블 탭 뒤로가기**: 선택(단일 탭) 제스처를 빠르게 두 번 입력하면 자동으로 '뒤로가기' 실행

---

## APK 파일 만드는 방법 (2가지)

### 방법 A: PC에 Android Studio가 있는 경우
1. 본 압축 파일(`R08_MemoMind_Bridge_Project.zip`)의 압축을 풉니다.
2. **Android Studio** 실행 -> **[Open]** -> 압축을 푼 폴더 선택.
3. 상단 메뉴 **[Build] -> [Build Bundle(s) / APK(s)] -> [Build APK(s)]** 클릭.
4. 생성된 `app-debug.apk`를 스마트폰에 넣고 설치합니다.

### 방법 B: PC에 개발 환경이 없는 경우 (GitHub 무료 자동 빌드)
이 프로젝트에는 `.github/workflows/build-apk.yml` 자동 빌드 스크립트가 포함되어 있습니다.
1. GitHub에서 새 저장소(Repository)를 만들고 압축 푼 파일들을 그대로 업로드(Push)합니다.
2. 상단 **[Actions]** 탭으로 이동하면 자동으로 APK 빌드가 시작됩니다.
3. 빌드가 완료되면 **Artifacts** 항목에서 `R08-MemoMind-Bridge-Debug-APK`를 다운로드하여 스마트폰에 설치합니다.
